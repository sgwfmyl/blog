# 混合架构改造策略报告 v3（静态 + SSR + Server Islands）

> 日期：2026-10-16（v3 修订，采纳审查意见 1-9 + 二轮意见 1-5）
> 基线假设：在**无隐私/私密架构**的干净分支上执行（`private/` 相关文件已移除），报告即执行标准。
> 目标项目：Astro 7.1.6 纯静态博客（38 页面文件 + Starlight docs / 15 Content Collections / 全局 Swup SPA / Pagefind / Cloudflare Workers Static Assets 部署）。
> **版本核查要求**：本报告部分描述基于旧版 Astro 认知，**凡涉及 7.x 与 Workers 的具体行为（output 语义、静态未命中回退、server-island 与 Swup 交互、`not_found_handling`/`run_worker_first` 语义）一律以官方文档为准，逐条对照实测后再固化**。

---

## 1. 目标与约束

### 1.1 目标

- 私密内容来自私有仓库，登录后才可见，退出登录后失效并"卸载"；
- 私密内容**像静态内容一样**出现在归档、目录、标签池、最近更新、卡片流、统计图表中（同权渲染）；
- 私密文章与公开文章**同一路由前缀**（`/posts/*`），点进即文章页排版；
- **只维护一套渲染逻辑**（一份 .astro 组件），不做静态/动态两套系统；
- 组件功能与页面样式**保持不变**，改动集中在路由与数据层。

### 1.2 硬约束

- 私密内容**不得进入部署产物**（游客抓取 dist 拿不到任何内容与标题）；
- 公开内容保持构建期静态 + CDN 全缓存的性能与 SEO；
- 未授权访问私密内容一律 **404**（不泄露其存在），页面 `noindex`；
- 鉴权、密钥全部在服务端（环境变量），token 不进浏览器；
- **私密源异常（GitHub 限流 / 存储失效）时降级到公开基线**，不报错、不泄露错误详情；
- **吊销语义诚实**：报告不承诺"立即"，只承诺明确可实现的吊销窗口（见 2.4）。

## 2. 架构决策（执行标准）

### 2.1 渲染模式

> Astro 5 起已无 `output: 'hybrid'`，静态输出本身即可让单个页面用 `prerender = false` 切为 SSR。**不写 output（保持默认 `static`）**，安装适配器后需要动态的页面显式 `prerender = false`。

| 项 | 决策 | 理由 |
| --- | --- | --- |
| 输出模式 | **默认 `output: 'static'`（不显式写）** | Astro 5+ 静态输出即支持单页 `prerender=false` |
| SSR 适配器 | `@astrojs/cloudflare` | SSR/岛屿必须有适配器；部署目标即 Cloudflare Workers |
| 公开文章详情 | 静态预渲染 | CDN 全缓存、SEO 最优，**保持现状不改** |
| 布局/导航骨架 | 静态 | 保持性能 |
| 标签池/最近更新/统计数字 | **Server Island**（`server:defer`） | 局部聚合需含私密条目，组件模板不改，只加薄包装 |
| 归档页/目录页（含**卡片流**） | **整页 SSR**（`prerender=false`） | 需要公开/私密统一排序计数；流量小，最简单可靠 |
| 私有文章详情 | **SSR 兜底路由**（见 2.6） | slug 构建时未知，无静态外壳可挂 |
| 登录/登出 | SSR 端点 | 设置/吊销会话（见 2.4） |

### 2.2 岛屿与 SSR 的选用法则

- 公开为主、私有为局部 → **Server Island**（`server:defer`，静态页面内嵌动态片段）；
- 整页私有 / 路由本身私有 / 需要整页统一排序计数 → **整页 SSR**；
- **不使用 `client:*` 岛屿重绘聚合组件**（避免 Astro 与框架组件两套渲染）。

### 2.3 数据层（核心：挂载/卸载发生在数据层）

```
展示层(.astro 组件，一份，纯函数，只接收条目列表)
   │ 只调用 getAll(authed) / getBySlug(slug, authed)
内容聚合层 src/lib/content.ts（ContentSource 抽象）
   ├─ 静态源：包装 getCollection（公开，构建时/运行时皆可用）
   │   提供两档：getAllMeta()（只读元数据轻量路径，见 2.7）与 get(slug)（正文）
   └─ 私有源：Git 私有仓库 → 运行时拉取 + 缓存；未授权返回 null（= 卸载）
```

关键规则：
- `getAll(authed)` = 静态源 + (authed ? 私有源 : 无) → 合并 → 统一排序/计数/过滤；
- **统计（countTags / groupByYear）在合并之后计算**，禁止在静态部分提前聚合；
- 私有 Markdown 在 SSR 侧复用与公开相同的 remark/rehype 管线（共享配置文件），保证渲染一致；
- **slug 命中顺序**：`getBySlug` 一律**公开优先、私有兜底**（重名时公开胜出，规则固定），`getAll` 合并时私有条目不覆盖公开条目。

### 2.4 鉴权与会话（修正：吊销语义诚实化）

- `middleware.ts`：`ctx.locals.authed = verifySession(cookie)`；
- 单用户：密码哈希 + 有状态会话；
- **会话存储（修订）**：Cloudflare KV 是**最终一致**，删除后其他边缘节点仍可能短暂读到旧值（约 60 秒窗口，以官方文档为准）——因此：
  - **主选：会话存 Durable Object 或 D1**（强一致读写，单用户成本可忽略，登出删除即全站生效）；
  - 备选：仍用 KV，但**验收标准写成"吊销窗口 ≤ 约 60 秒"**，并配套短 TTL 会话令牌（如 15 分钟滑动过期），不得在报告/验收里使用"立即失效"字样；
- **登出**：仅 `POST` + 校验 `Origin`/`Referer` 同源（防 GET 链接诱导登出）；响应加 `Clear-Site-Data: "cache"`；
- **bfcache 处理**：页面 `pageshow` 事件检测 `event.persisted` 为真时强制刷新（防后退恢复登出前内存页面）；
- **登录防爆破（修订）**：登录限流计数器**不放 KV**（计数不准）；改用 **Cloudflare 自带 Rate Limiting 规则**，可选 **Turnstile** 人机验证；
- **每个 SSR 页面与每个 Server Island 内部自行判断鉴权**（岛屿是独立请求，不继承外壳判断）；
- SSR 与岛屿响应设置 `Cache-Control: private, no-store`。

### 2.5 私有数据源

- 私有仓库 + 只读 token，token 只存服务端环境变量；
- 运行时经 GitHub Contents API 拉取 + 缓存（先内存跑通，再上 KV/D1）；
- **异常降级**：拉取失败/限流/缓存失效时，私有源返回空（视同未登录），公开基线不受影响；错误详情只写服务端日志，绝不进入响应；
- 私密内容**不得放进公开仓库**（否则被构建进产物）；
- 敏感数据（日记/账单）若量大建议数据库（D1），本报告以仓库 + 缓存为准。

### 2.6 同前缀路由形态

`prerender` 是**文件级**属性，同一文件只能 true 或 false；同一路由模式不能放两个文件。采用**不同参数形态**并存：

- `posts/[slug].astro`：**静态**（`getStaticPaths` 生成全部公开文章）→ 覆盖公开文章；
- `posts/[...rest].astro`：**SSR 兜底**（`prerender=false`）→ 覆盖未命中静态的所有路径（含私有 slug、嵌套 slug）；
- **关键前提 A（静态未命中回退）**：静态资产未命中时请求是交给 Worker 还是直接 404，取决于 wrangler assets 配置（`not_found_handling`、是否 `run_worker_first` 等，具体语义以官方文档为准）。**配置不对时，即使 `[...rest]` 写对了，私有文章也永远到不了 SSR**。此项必须写入阶段 2 验证清单；
- **关键前提 B**：该回退行为在 Cloudflare 适配器下**必须实测**，并提前到阶段 2；
- 优先级规则：公开命中即公开；未命中走 SSR → `getBySlug` 公开优先、私有兜底；两者皆无 → 404。

### 2.7 岛屿与 fallback 如何共用同一组件（修订：三层拆分）

绝不在图标组件内部读 Cookie、也不把 `authed` 作为 prop 传入岛屿。拆成三层：

```
展示组件（纯函数 .astro，只接收 List<Entry>，渲染条目列表）
   ├─ 静态包装（构建期）：固定传入公开数据 → 产出公开 fallback HTML
   └─ 岛屿包装（server:defer，构建期渲染 fallback 外壳 + 运行时请求）：
         运行时从 Cookie 自取身份 → 调 getAll(authed) → 复用同一展示组件渲染
```

要点：
- **展示组件做成纯函数**，只接收条目列表，不含任何鉴权判断；
- **静态包装**：构建期用公开数据固定渲染出 fallback；
- **岛屿包装**：`server:defer`，服务端从 Cookie 取身份（不传 prop），再调 `getAll`，传递给同一展示组件；
- **禁止把 `authed` 作为 prop 传给岛屿**（props 会序列化进 URL 变成可信任输入）。

### 2.8 Worker 体积与数据形态

- SSR 页面在运行时调用 `getCollection` 可能把 **Content Layer 数据一并打进 Worker bundle**；
- **静态源提供只读元数据轻量路径**：聚合页（归档/目录/统计）只消费 `{slug,title,date,tags,category,type}` 元数据，不加载正文/图片；正文加载仅发生在详情页路径；
- 风险表（§5）覆盖 unified 管线进 Worker 的同时，**必须同计 shiki/expressive-code 等重型插件**的打包体积。

## 3. 分阶段实施策略

> 每阶段必须通过验收标准后才能进入下一阶段；任一阶段失败即止损回退，损失停留在该阶段；**每个阶段失败点都写明后续路线怎么改**。

### 阶段 0：基线确认 + 范围清点

- 干净分支上确认：移除 `private/` 相关文件、`pnpm build` + `pnpm check` + `pnpm type-check` 全绿；
- 记录公开页面当前 HTML 输出作为回归对照基线（**diff 时排除文件名哈希、构建时间戳、pagefind 数据等非确定性内容**）；
- 保留现认证/会话实现代码作为复用素材（迁移至 middleware，不重写安全逻辑）；
- **清点表（必做，逐行穷尽，见 §8 附录）**：40 行全部列出，每行 = 页面/端点 × 依赖集合 × 处理方式 × 是否含私密条目 × 是否产出衍生文件。**凡依赖 `posts` 的页面或端点，均为泄露/未挂载风险点，逐一核对**。

### 阶段 1：数据层统一（零行为变化，先吃收益）

- 抽出 `src/lib/content.ts`：`ContentSource` 接口 + `getAllMeta`/`getAll`/`getBySlug`；
- 先只有静态源；归档、目录、标签池、最近更新等聚合组件全部改调统一接口；
- **验收**：构建通过，公开页面 HTML 与基线 diff 为空（排除非确定性内容后）。

### 阶段 2：SSR 能力 + 最小验证集（四项风险全在此阶段实测）

- 安装 `@astrojs/cloudflare`，确认 output 默认 `static` 下 `prerender=false` 生效；
- **四项最小验证，每项写明失败止损路线**：

| # | 验证项 | 失败时的止损路线 |
| --- | --- | --- |
| 1 | 最小 SSR 页面（`prerender=false`）构建、部署、线上可访问；并与现有 `/api/*` 手工 Worker 逻辑合并跑通 | 回退到阶段 1 结束状态，重新评估适配器/部署形态 |
| 2 | **Swup × 一个最小 `<server-island>`**：SPA 换页时岛屿能否重新加载 | **退回"整页 SSR + 不用岛屿"**：聚合点全部改为整页 SSR（公开页损失静态收益，但方案成立） |
| 3 | **静态未命中 → SSR 回退**：在 Cloudflare 适配器 + wrangler assets 配置（`not_found_handling`/`run_worker_first`）下是否成立 | **退回"公开文章也走 SSR"**：`posts/[...slug]` 统一 SSR，放弃同前缀静态方案 |
| 4 | **wrangler assets 回退配置**：`/posts/` 首页、分页（`/posts/page/2`）、trailing slash、缺省/嵌套 slug 的实际路由命中行为 | 同 #3，路由方案整体重定 |

- **验收**：四项逐项通过并记录结论；任一不通过即按上表止损，不进入阶段 3。

### 阶段 3：私有数据源 + 鉴权

- middleware 鉴权 + 会话 id + **D1/Durable Object 存储**（或 KV + 短 TTL，见 2.4）；
- 登录/登出 SSR 端点（登出 POST + 来源校验 + `Clear-Site-Data`）；登录防爆破用 Cloudflare Rate Limiting / Turnstile；
- 实现私有 `ContentSource`（GitHub 拉取 + 缓存 + 异常降级）；
- **验收**：curl 未登录访问私有页 = 404；登录后 SSR 页面含私密条目；登出后吊销生效（**按 2.4 的吊销窗口标准验收，不用"立即"**）；私密源故障时页面退回公开基线。

### 阶段 4：路由改造（同前缀）

- 按 2.6 落地 `posts/[slug].astro` + `posts/[...rest].astro`（阶段 2 已实测回退行为，此处正式化）；
- **验收**：公开 URL 正常；私有 URL 登录可读、未登录 404；嵌套 slug 正常；公开/私有重名时公开胜出；`/posts/` 首页、分页、trailing slash 行为符合阶段 2 结论。

### 阶段 5：岛屿化

- 标签池/最近更新/统计组件按 2.7 三层拆分：展示组件纯函数 + 静态包装 + 岛屿包装 `server:defer`（fallback 放构建期公开版本）；
- 归档/目录页切整页 SSR；
- **验收**：未登录见公开 fallback；登录见合并版；**fallback 控制尺寸，无布局抖动**；岛屿不接收 `authed` prop。

### 阶段 6：Swup 缓存安全

- **双向清理**：登录时清 Swup 缓存（避免登录前缓存的公开版归档继续显示，看起来"私密没挂上"）；登出时清 Swup 缓存（防私密 HTML 残留）；
- 缓存头核查：SSR 与岛屿响应 `private, no-store`；
- bfcache：登出后 `pageshow` 刷新；
- **验收**：登录后 SPA 切页岛屿正常加载；登出后回退/预载不出现任何私密内容；登录/登出均无缓存残留。

### 阶段 7：索引与衍生文件泄露检查

- 逐项核对**构建期衍生文件**（见 §8 尾列）：`rss.xml.ts`、`og/[...slug].png.ts`、`api/calendar.json.ts`、Pagefind 搜索索引——这些在构建期生成，天然不含 SSR 私密内容，但必须**确认不含**，并确认 sitemap/robots 规则；
- 私密页面 `noindex`；
- **验收**：未登录状态下抓取全部页面、API 端点、衍生文件、岛屿端点，确认无私有标题、数量、标签泄露。

### 阶段 8：部署改造

- wrangler.toml 重构：Astro 集成接管 Worker 入口，与 `/api` 认证逻辑合并；workers assets 回退配置固化（阶段 2 结论）；
- GitHub Actions workflow 调整；
- **验收**：线上全量回归通过。

## 4. 关键技术决策点与备选

| 决策点 | 主选 | 备选 | 说明 |
| --- | --- | --- | --- |
| 文章详情同前缀 | `[slug]` 静态 + `[...rest]` SSR 兜底 | `posts/[...slug]` 全量 SSR | 回退行为已在阶段 2 实测；全量 SSR 仅当兜底不成立才采用 |
| 归档/目录页 | 整页 SSR | 静态外壳 + 列表岛屿 | 整页 SSR 最简单可靠；岛屿仅当需保留静态收益时 |
| 私有详情 | SSR 兜底（`[...rest]`） | `posts/[...slug]` 全量 SSR | 无静态产物可挂时只能 SSR |
| 会话存储 | **D1 / Durable Object（强一致）** | KV + 短 TTL（吊销 ≤60s） | 强一致可即时吊销；KV 需诚实标注窗口 |
| 登录限流 | Cloudflare Rate Limiting / Turnstile | — | 不用 KV 计数（不准） |
| 私有数据缓存 | KV/D1 TTL 5 分钟 | Webhook 同步 | 先缓存跑通，量大再上 Webhook |
| 聚合数据形态 | 只读元数据轻量路径 | 完整 collection | 避免 Content Layer 数据打进 Worker（2.8） |
| 岛屿组件形态 | 三层拆分（纯函数+两包装） | — | 不传 authed prop，见 2.7 |
