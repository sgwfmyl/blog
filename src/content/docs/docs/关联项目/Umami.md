Umami 是一个面向隐私保护的开源 Web 分析平台，核心目标是让站点拥有分析能力，同时尽量避免收集用户个人数据。

它的优势主要包括：

1. 不依赖 Cookie 和用户标识，减少 GDPR 等合规风险。
2. 支持自定义事件跟踪，用于按钮点击、表单提交、页面交互等埋点。
3. 具备多种典型分析能力：页面浏览量、访客数、跳出率、会话时长、来源、浏览器、系统、设备和区域统计。
4. 提供团队协作、共享网站、角色权限、REST API 等能力。

## 典型功能

Umami 的分析功能主要覆盖：

- 核心分析：页面浏览量、访客、跳出率、会话时长、推荐来源、浏览器、操作系统、设备和国家统计。
- 自定义事件：通过数据属性或 JS API 跟踪按钮点击、表单提交、业务交互。
- 高级分析：漏斗、用户路径、留存、目标、UTM、群组细分等能力。
- 会话分析：查看单个访客会话、活动详情和属性。
- 团队与共享：共享网站、分配角色、管理团队成员权限。
- API：提供完整的 REST API，便于程序化取数或扩展。
