## 概述

书影音集合用于 `/bangumi` 页面的「看过 / 读过 / 玩过」卡片墙，记录影视、书籍、游戏的评分与短评。

- **物理目录**：`src/content/bangumi/**/*.{md,mdx,yaml,yml}`，一个文件 = 一条条目
- **集合定义**：`src/content.config.ts` 的 `bangumiCollection`
- **展示页面**：`src/pages/bangumi.astro`（`/bangumi`，单页卡片墙，无详情页）
- 一级子目录即大类：`anime/`（影视）、`book/`（书籍，可再嵌套如 `book/文学/`）、`game/`（游戏）
- **当前页面只渲染影视、书籍、游戏三个 Tab**

## Frontmatter 字段

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `title` | string | 是 | — | 作品名 |
| `category` | enum | 否 | `anime` | 大类：`book`（书）/ `anime`（影视）/ `game`（游戏） |
| `subcategory` | enum | 否 | — | 影视细分类：`movie` / `tv` / `anime` / `documentary` |
| `status` | integer 1–5 | 否 | `2` | 观看状态：`1` 想看、`2` 看过、`3` 在看、`4` 搁置、`5` 抛弃 |
| `image` | string 或图片 | 是 | — | 封面图。实际数据统一填图床/远程 URL（如 `https://img.tsh520.cn/file/blog/bangumi/xxx.webp`），schema 也兼容本地图片 |
| `score` | number 0–10 | 否 | — | 个人评分，卡片上渲染为星星 + 数字（`10.0` 显示为 `10`） |
| `tags` | string\[] | 否 | `[]` | 标签 |
| `published` | date | 否 | — | 记录时间，**条目按它倒序排列**；缺失时取当前时间（排最前） |
| `name_cn` | string | 否 | — | 中文译名 |
| `link` | string | 否 | — | 关联文章链接；**留空时自动推导**（见下文） |
| `comment` | string | 否 | — | 短评字段；实际习惯直接写在**正文**里 |

正文（frontmatter 之后）写一句话短评或读书笔记，卡片与弹窗会展示。

## 链接自动推导

`link` 留空时（`src/pages/bangumi.astro`）：

1. 先用文件 id 拼成 `/bangumi/<id>/`（保留子目录、仅去扩展名）
2. 再用 id / 标题去 `posts` 集合匹配**同名文章**，命中则把链接改写成 `/posts/<文章slug>/`，卡片点击直接跳到对应博客文章

所以为某个作品写了同名文章后，书影音卡片会自动关联，无需手填 `link`。

## 文件命名与排序

- 文件名即作品名，如 `肖申克的救赎.md`；书名放在分类子目录中，如 `book/文学/追风筝的人.md`
- 排序只看 `published`（倒序），与文件名无关；补填旧日期的记录会排到对应时间位置

## 导入脚本

- `scripts/下载影视/index.py`：从豆瓣 / bgm.tv 搜索作品信息与封面，自动生成条目 md（默认输出到 `src/content/bangumi/anime/`）
- 书籍条目常见由微信读书导入，会带额外的 `doc_type: weread-highlights-reviews`、`bookId`、`wereadCategory` 等字段（划线笔记格式，schema 未限制额外字段）

## 示例

影视（最常见）：

```yaml
---
title: 肖申克的救赎
category: anime
status: 2
image: https://img.tsh520.cn/file/blog/bangumi/肖申克的救赎.webp
score: 10
tags:
  - 剧情
  - 犯罪
  - 经典
published: 2025-01-09
---
能救赎自己的只有自己
```

书籍（放在子分类目录中，可关联微信读书划线正文）：

```yaml
---
title: 富爸爸穷爸爸
category: book
status: 2
image: https://cdn.weread.qq.com/weread/cover/68/YueWen_23601930/t6_YueWen_23601930.jpg
tags:
  - 经济理财-理财
published: 2026-09-18
---
正文放书摘与读书笔记。
```

游戏（标记为抛弃）：

```yaml
---
title: 英雄联盟
category: game
status: 5
image: https://img.tsh520.cn/file/blog/bangumi/英雄联盟.webp
score: 9.5
published: 2026-08-02
---
青春结束了。
```
