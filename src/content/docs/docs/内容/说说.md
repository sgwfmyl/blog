## 概述

说说集合用于 `/moments` 页面的动态流（类似社交动态/朋友圈，正文支持 Markdown 与 emoji）。

- **物理目录**：`src/content/moments/**/*.{md,mdx}`，一个文件 = 一条说说
- **集合定义**：`src/content.config.ts` 的 `momentsCollection`
- **展示页面**：`src/pages/moments.astro`（`/moments`）、置顶子页 `src/pages/moments/pinned.astro`
- 其余消费点：侧栏组件 `RecentItems.astro`、`SiteStats.astro`、首页 `HomeTicker.astro` 等

## Frontmatter 字段

| 字段          | 类型                 | 必填 | 默认值                        | 说明                                                  |
| ----------- | ------------------ | -- | -------------------------- | --------------------------------------------------- |
| `published` | date               | 是  | —                          | 发布时间，YAML 写 `2026-09-28 15:09:00` 或 `2026-09-28` 均可 |
| `id`        | string             | 否  | `""`                       | 条目 id，`pnpm cli moment` 生成时 = 文件名去除连字符（如 `202610100035`） |
| `author`    | string             | 否  | `"lh"`                     | 作者名                                                 |
| `avatar`    | string             | 否  | `"/assets/ziyuan/tx.webp"` | 头像路径（`public/` 下）                                   |
| `pinned`    | boolean            | 否  | `false`                    | 是否置顶（置顶说说展示在 `/moments/pinned`）                     |
| `images`    | string 或 string\[] | 否  | `[]`                       | 配图列表；单个可写字符串。支持远程 URL，也支持本地相对路径（走 Astro 图片管线）       |
| `tags`      | string\[]          | 否  | `[]`                       | 标签，如 `日常`、`coc`                                     |
| `location`  | string             | 否  | `""`                       | 地点，如 `河南-郑州`                                        |
| `device`    | string             | 否  | `""`                       | 发布设备                                                |

## 文件命名规则

- 一个文件 = 一条说说，文件名 = 创建时间 `YYYY-MM-DD-HHmm.md`（含年月日时分），如 `2026-10-10-0035.md`
- 时间戳精确到分钟，当天多条说说不会重名
- `id` 字段 = 文件名去除连字符（如 `2026-10-10-0035.md` → `202610100035`），由创建命令自动生成

## 快速创建（CLI）

运行 `pnpm cli moment [可选正文]` 自动创建一条说说：

- 在 `src/content/moments/` 生成以当前时间命名的文件（年月日 + 时分，当天多条不重名）
- Frontmatter 展示全部默认字段：`published` 取当前时刻、`id` = 文件名去连字符、`author: lh`、`avatar: /assets/ziyuan/avatar01.webp`、`pinned: false`、`images: []`、`tags: []`、`location: ""`、`device: ""`
- 可选参数作为正文；不传则为空正文，之后在文件里补写

## 正文与图片

- **正文**：frontmatter 结束后的内容就是说说正文，支持 Markdown 语法和 emoji，空行即分段
- **图片必须走图床**：说说配图一律上传到博客图床（路径前缀 `https://img.tsh520.cn/file/blog/moments/...`），frontmatter 的 `images` 填图床 URL。图床图片与博客仓库解耦，本地仓库不存放说说图片文件
- 不推荐在 `src/content/moments/assets/` 存放图片：本地图片会随仓库体积膨胀，且与「图床统一管理」的约定相悖

## 示例

纯文字（最常见）：

```yaml
---
published: 2026-09-28 15:09:00
tags:
  - 日常
---
肠胃炎好像犯了，好难受，明明刚吃过饭肚子里又撑又饿…
```

带图片 + 多标签：

```yaml
---
published: 2026-09-28 19:00:37
tags:
  - 日常
  - coc
images:
  - https://img.tsh520.cn/file/blog/moments/1790593237409_media_image_xxx.jpg
---
庆祝一下部落21级了
```

带地点：

```yaml
---
published: 2026-05-06 00:00:00
tags:
  - 日常
location: 河南-郑州
---
更换现有按钮的点击效果（已完成）
```
