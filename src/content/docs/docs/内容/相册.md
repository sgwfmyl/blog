## 概述

相册集合用于 `/album` 页面的「一面照片墙」：系统把所有相册的照片**拆开打散**，按最新在前铺满整个内容区，顶部提供搜索 / 相册 / 标签筛选，点任意照片打开灯箱大图。

- **物理目录**：`src/content/album/**/*.{md,mdx,json}`，一个文件 = 一个相册
- **集合定义**：`src/content.config.ts` 的 `albumCollection`
- **展示页面**：`src/pages/album/index.astro`（`/album`，单相册页 `/album/<id>/` 已删除）
- **关键约定**：**照片一律走图床（`imgbedFolder`）**，前端在浏览器里并行拉取，不再在仓库内维护照片

## Frontmatter 字段

| 字段             | 类型               | 必填 | 默认值     | 说明                                                                         |
| -------------- | ---------------- | -- | ------- | -------------------------------------------------------------------------- |
| `title`        | string           | 是  | —       | 相册标题，展示在筛选条标签上                                                             |
| `date`         | date             | 是  | —       | 相册日期（YAML 写 `2026-09-30`），照片墙按此降序排序                                        |
| `imgbedFolder` | string           | 否  | `""`    | **图床文件夹路径**，指向 CloudFlare ImgBed 下的目录；设置后前端从该文件夹动态加载全部照片（当前页面的实际照片来源，核心字段） |
| `subtitle`     | string           | 否  | `""`    | 副标题/简介                                                                     |
| `location`     | string           | 否  | `""`    | 地点（参与搜索与照片墙元信息展示），如 `郑州`                                                   |
| `tags`         | string\[]        | 否  | `[]`    | 标签（顶部显示一排子标签，点击可筛选该相册内的照片）                                                 |
| `draft`        | boolean          | 否  | `false` | 草稿；生产构建会隐藏（`PROD` 下 `draft: true` 不进照片墙）                                   |
| `cover`        | string(图片)       | 否  | —       | 封面图。schema 保留（兼容），**当前照片墙不使用**，封面由前端取图床文件夹首图                               |
| `photos`       | string\[] 或对象\[] | 否  | `[]`    | 照片列表。schema 保留（兼容旧版单相册页），**当前照片墙不使用**——照片统一由 `imgbedFolder` 图床动态加载         |

> 说明：`photos` 每个元素可以是图片路径字符串，也可以是 `{ src, alt?, caption? }` 对象（形如动效配置）。这是旧版单相册页的历史字段，改版后不再消费，是否沿用取决于你。

## 图床约定（核心）

- **照片必须走图床**：在 frontmatter 填 `imgbedFolder`（如 `blog/album/ai生图`），指到 CloudFlare ImgBed 的某个文件夹，把照片传到该目录即可，**无需改动仓库**。
- **靠环境变量取图**：`src/pages/album/index.astro` 从 `PUBLIC_IMAGEBED_URL` / `PUBLIC_IMAGEBED_API_TOKEN` 读取图床地址与 Token，用 `imgbedFolder` 调 `list` 接口拉取照片列表，再拼接缩略图地址铺墙。**未配置环境变量时照片墙显示「未配置图床 API Token」**。
- 改版（2026-09-30）后照片墙单页拉全部相册的图床文件夹，照片数量多时在浏览器端并行分页拉取（每批 100 张）。
- **支持视频混排（2026-10-10）**：`imgbedFolder` 指向的文件夹里同时放图片和视频（mp4 等）即可混排进照片墙。
  视频在墙上以首帧缩略图展示（带播放角标），点开在灯箱里用 `<video controls>` 播放；切换/关闭时自动暂停。
  无需改动文件字段或 schema。

## 文件命名规则

- 一个文件 = 一个相册，文件名即相册 id（默认），如 `ai生图.md` → id `ai生图`
- 不需要手动维护 `id` 字段；集合定义里没有 `id` 字段，id 由 `astro:content` 按文件名自动生成
- 文件内 frontmatter 之后的内容可作为补充描述正文（如 `游戏记录.md` 里的 `游戏日常记录`），不影响照片墙

## 示例

最简（纯图床相册）：

```yaml
---
title: 说说和足迹
date: 2026-09-30
imgbedFolder: blog/moments
---
```

带副标题 + 地点 + 标签（站点常用风格）：

```yaml
---
title: 风景照
subtitle: 来自图床的风景相册
date: 2026-07-29
tags:
  - 图床
imgbedFolder: "blog/album/风景"
---
```

完整字段（含旧版兼容字段 `cover` / `photos`，当前照片墙不读）：

```yaml
---
title: AI生成图片
subtitle: 记录AI生成的图片
date: 2026-08-13
location: ""
tags:
  - 图床
draft: false
imgbedFolder: "blog/album/ai生图"
cover: ""
photos: []
---
```
