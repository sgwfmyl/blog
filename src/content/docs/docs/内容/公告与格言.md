---

## 概述

资源集合（ziyuan，「资源卡片」）不是普通列表页内容，而是供站点多个位置按 **id 取用**的小卡片，目前有两种互斥形态：**公告**（content 形态）和**格言**（quotes 形态）。

- **物理目录**：`src/content/ziyuan/**/*.md`
- **集合定义**：`src/content.config.ts` 的 `ziyuanCollection`（zod 联合类型：两种形态二选一）
- 没有独立路由页面，消费方通过固定 id 查找：
  - `announcement` → 侧栏公告组件 `src/components/widget/Announcement.astro`、Dock 公告抽屉（`UnifiedDock.astro` / `FloatingDock.astro`）
  - `quote` → 侧栏「每日一言」`src/components/widget/QuoteOfTheDay.astro`

## 形态一：公告（content + link）

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `title` | string | 是 | — | 卡片标题，如 `公告` |
| `content` | string | 是 | — | 公告正文 |
| `closable` | boolean | 否 | `true` | 是否显示关闭按钮（读者可手动关闭，状态记在本地） |
| `link.enable` | boolean | 否 | `true` | 是否展示链接按钮 |
| `link.text` | string | 是（配 link 时） | — | 按钮文案，如 `了解更多` |
| `link.url` | string | 是（配 link 时） | — | 链接地址，可写站内路径（`/about/`）或外部 URL |
| `link.external` | boolean | 否 | `false` | 是否外链；`true` 时 `target="_blank"` 新窗口打开 |

文件即 `src/content/ziyuan/announcement.md`（id 必须为 `announcement`，消费方按此 id 查找）。

## 形态二：格言（quotes）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `title` | string | 是 | 卡片标题，如 `每日一言` |
| `quotes` | `{ text, author }[]` | 是 | 名言数组；`text` 为内容，`author` 为作者（未知可写 `未知`） |

文件即 `src/content/ziyuan/quote.md`（id 必须为 `quote`）。组件按日期作种子，**每天自动换一条**，无需手动维护当日选哪条。

## 示例

公告：

```yaml
---
title: 公告
content: 如果你喜欢，那么欢迎来到我的世界！
closable: true
link:
  enable: true
  text: 了解更多
  url: /about/
  external: false
---
```

格言：

```yaml
---
title: 每日一言
quotes:
  - text: 生活不是等待暴风雨过去，而是学会在雨中跳舞。
    author: 塞维涅夫人
  - text: 人生如逆旅，我亦是行人。
    author: 苏轼
---
```
