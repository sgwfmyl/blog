## 概述

日程集合用于 `/schedules` 页面的日历事件（普通安排、生日、纪念日、节假日）。

- **物理目录**：`src/content/schedules/**/*.{md,mdx}`，一个文件 = 一个事件
- **集合定义**：`src/content.config.ts` 的 `schedulesCollection`（zod schema + `superRefine` 校验）
- **展示页面**：`src/pages/schedules.astro` + `src/components/schedules/SchedulesView.svelte`
- 事件信息全部写在 frontmatter，正文可留空

## Frontmatter 字段

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `title` | string | 是 | — | 事件标题，显示在日历格子与列表中 |
| `date` | date（自动 coerce） | 条件必填 | — | 阳历日期，YAML 写 `2026-08-25` 或完整 ISO 字符串均可；`isLunar: false` 时必填 |
| `endDate` | date（自动 coerce） | 否 | — | 结束日期；当前仅存储，页面暂未消费（预留） |
| `allDay` | boolean | 否 | `false` | 是否为全天事件 |
| `priority` | enum | 否 | `"none"` | 优先级：`none` / `low` / `medium` / `high`，决定事件列表圆点颜色 |
| `status` | enum | 否 | `"todo"` | 状态：`todo`（待办）/ `done`（已完成）/ `cancelled`（已取消） |
| `location` | string | 否 | `""` | 地点 |
| `repeat` | string | 否 | `""` | 重复规则自由文本（如 `"每年"`）；当前仅存储展示，页面不会据此自动展开重复事件 |
| `category` | enum | 否 | `"schedule"` | 分类：`schedule`（普通日程）/ `birthday`（生日）/ `anniversary`（纪念日）/ `holiday`（节假日），决定日历样式与列表分组 |
| `person` | string | 否 | `""` | 相关人物（生日、纪念日场景使用） |
| `isLunar` | boolean | 否 | `false` | 是否按农历日期排期 |
| `lunarMonth` | integer 1–12 | 条件必填 | — | 农历月；`isLunar: true` 时必填 |
| `lunarDay` | integer 1–30 | 条件必填 | — | 农历日；`isLunar: true` 时必填 |
| `lunarLeap` | boolean | 否 | `false` | 农历月是否为闰月 |

## 校验规则

schema 通过 `superRefine` 追加了两条跨字段校验，构建时不满足会直接报错：

1. **非农历事件必须填 `date`**：`isLunar` 非 `true` 且缺少 `date` → 报错「非农历需填 date」
2. **农历事件必须填 `lunarMonth` + `lunarDay`**：`isLunar: true` 但二者缺任一个 → 报错「农历需填 lunarMonth/lunarDay」

即：阳历事件只写 `date`，农历事件只写 `lunarMonth`/`lunarDay`（不写 `date`，写了也会被当年换算结果覆盖）。

## 农历日期机制

农历事件（如家人农历生日）不需要手动换算阳历，也不用每年改文件：

- **服务端预换算**：`schedules.astro` 构建/请求时用 `lunar-javascript` 把农历月日换算成**当前年份**的阳历日期写入 `date`，消除首屏闪烁
- **客户端动态换算**：`SchedulesView.svelte` 在日历年/月切换时，按**当前显示的年份**重新换算，所以翻到未来年份，农历生日会自动落到对应的阳历日期
- 换算参数为 `lunarMonth`、`lunarDay`、`lunarLeap`（闰月标记）

## 示例

阳历日程：

```yaml
---
title: 团队周会
date: 2026-10-12
endDate: 2026-10-12
allDay: false
priority: medium
status: todo
location: 会议室 A
category: schedule
---
```

农历生日（无需写 `date`，每年自动换算）：

```yaml
---
title: 我的生日
allDay: true
priority: none
status: todo
repeat: 每年
category: birthday
person: 我
isLunar: true
lunarMonth: 8
lunarDay: 24
---
```
