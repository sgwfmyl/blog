## 概述

笔记本集合用于「生活」下的日记本/笔记本（书架式展示：一本笔记本 = 一个子文件夹，内含多篇笔记）。

- **物理目录**：`src/content/life/notebooks/**/*.{md,json}`
- **集合定义**：`src/content.config.ts` 的 `notebooksCollection`
- **展示页面**：索引页 `src/pages/life/notebooks/index.astro`（书架 + 最新笔记）、详情页 `src/pages/life/notebooks/[...slug].astro`

## 目录结构与读取规则

一本笔记本 = 一个**子文件夹**，由两个部分组成：

```
src/content/life/notebooks/
└── 随笔/                        ← 一本笔记本（子文件夹）
    ├── _index.json              ← 笔记本的「介绍/配置」文件（必建）
    ├── 2026年9月28日.md          ← 单篇笔记
    └── 2026年9月28日-1.md
```

- **读取**：loader 为 `glob("**/*.{md,json}")`，递归读取所有子文件夹；索引页通过 `entry.id` 识别——只有 `文件夹名/_index.json`（也支持 `_index.md`）被当作**笔记本根**，其 `name/cover/summary` 用于书架卡片；同文件夹下其余 `*.md` 全部作为该笔记本的笔记条目，按 `date` 倒序，最新一篇的日期即笔记本的「更新时间」。
- **`readme.md` / `readme` 会被排除**，不参与展示（只适合放仓库内说明），请勿用它当笔记本内容。
- **空态提示**（页面内置）：先建文件夹 → 再建 `_index.json` → 再放 `*.md` 条目。

## 字段归属：谁该写什么

### `_index.json` —— 笔记本级（每文件夹一个）

| 字段      | 类型     | 必填 | 默认值        | 说明                          |
| ------- | ------ | -- | ---------- | --------------------------- |
| `name`  | string | 否  | `"未命名日记本"` | 笔记本名称（书架卡片标题）              |
| `cover` | string | 否  | `""`        | 封面图：本地相对路径（`public/` 下，如 `/assets/images/notebooks/30.webp`）或远程 URL |
| `summary` | string | 否  | `""`        | 笔记本简介（书架卡片副标题）              |

### 单篇笔记 `*.md` —— 笔记级

| 字段      | 类型                | 必填 | 默认值 | 说明                                                          |
| ------- | ----------------- | -- | --- | ----------------------------------------------------------- |
| `name`  | string            | 否  | 文件名   | 笔记标题（缺省用文件名）                                            |
| `images` | string 或 string\[] | 否  | `""` | 配图列表；单个可写字符串，逗号/分号分隔的字符串也会在页面层归一为数组                   |
| `tags`   | string\[]          | 否  | `[]` | 标签                                                          |
| `date`   | date               | 否  | —    | 笔记日期，YAML 写 `2026-10-01` 或带时间均可（`z.coerce.date` 自动转换）     |

## 示例

`随笔/_index.json`：

```json
{
	"name": "随笔",
	"summary": "想写下来的话都放这里：随笔、长文、自我提醒、突然的感悟",
	"cover": "/assets/images/notebooks/30.webp"
}
```

`随笔/2026年10月2日.md`：

```yaml
---
name: 十月第一篇
images:
  - https://img.tsh520.cn/file/blog/notebooks/oct-1.webp
tags:
  - 日常
date: 2026-10-02
---
正文内容…
```
