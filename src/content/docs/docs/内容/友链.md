## 概述

友链集合用于 `/friends` 页面的好友卡片墙（页面底部还会合入《墓碑》集合）。

- **物理目录**：`src/content/friends/**/*.md`，一个文件 = 一个友链
- **集合定义**：`src/content.config.ts` 的 `friendsCollection`
- **展示页面**：`src/pages/friends.astro`（`/friends`）

## Frontmatter 字段

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `title` | string | 是 | — | 站点名称/博主名 |
| `imgurl` | string | 是 | — | 头像/站点图标 URL（一般用远程地址） |
| `desc` | string | 是 | — | 站点一句话简介 |
| `siteurl` | string | 是 | — | 站点链接（点击卡片跳转） |
| `weight` | number | 否 | `0` | 排序权重，**越大越靠前**（常用 10/20 拉开档位） |
| `enabled` | boolean | 否 | `true` | 是否启用；`false` 不在页面展示（软下线，不必删文件） |
| `added` | date | 否 | — | 上链日期；填写后有资格进入「新朋友」区 |
| `group` | enum | 否 | `other` | 分组：`friend`（我的朋友们）/ `other`（更多伙伴） |
| `tags` | string\[] | 否 | `[]` | 标签 |

## 排序与分区规则

页面逻辑（`src/pages/friends.astro`）：

1. 过滤掉 `enabled: false`
2. **新朋友区**：有 `added` 日期的条目按日期倒序取前 3，单独置顶展示，不再进入下面的分组
3. 分组展示：`group: friend` → 「我的朋友们」；缺省/`other` → 「更多伙伴」
4. 各分组内按 `weight` 降序排列

## 文件命名规则

- 惯例两位数字前缀 + 名称，如 `04-aye.md`、`01-tuanzi.md`
- 数字前缀仅用于文件管理观感，**实际排序只看 `weight`**；站长本人站点也可以用 `group: other` 放在伙伴区

## 示例

```yaml
---
title: 阿叶Ayeez的小站
imgurl: https://qiniu.ayeez.cn/avatar.jpg
siteurl: https://blog.ayeez.cn
weight: 10
enabled: true
desc: 记录学习历程，记录美好生活
added: 2026-04-22
group: friend
---
```
