## 概述

墓碑集合是「友链墓碑」：纪念已经关闭/停更的友情站点，展示在友链页底部的纪念区。

- **物理目录**：`src/content/tombstones/**/*.md`，一个文件 = 一块墓碑
- **集合定义**：`src/content.config.ts` 的 `tombstonesCollection`
- **展示位置**：没有独立路由，仅渲染在 `/friends` 页（`src/pages/friends.astro` 底部「友链墓碑」区）

## Frontmatter 字段

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `title` | string | 是 | — | 旧站名称 |
| `avatar` | string | 否 | — | 站点/博主头像 URL |
| `note` | string | 否 | — | 纪念语，如 `已停止维护，2025-11`（用于记录，当前模板暂未在页面上展示该字段） |

## 示例

```yaml
---
title: 拾光的旧站
note: 已停止维护，2025-11
---
```
