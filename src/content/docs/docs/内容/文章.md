## 概述

文章集合是站点最核心的内容类型，用于 `/posts` 文章列表、首页信息流、分类页、归档页与 RSS。

- **物理目录**：`src/content/posts/**/*.{md,mdx}`，一个文件 = 一篇文章
- **集合定义**：`src/content.config.ts` 的 `postsCollection`
- **展示页面**：详情 `src/pages/posts/[...slug].astro`（`/posts/<分类>/<文件名>/`）、列表 `src/pages/posts/[...page].astro`、分类 `src/pages/categories/**`、归档 `src/pages/archive.astro`
- **分类不写 frontmatter**：分类 = 文件所在的**文件夹路径**（见下文）

## 目录即分类

- 文章直接放进 `src/content/posts/` 下的中文分类文件夹，如 `技术分享/`、`博客指南/`、`AI使用/`
- 分类由文件路径自动推导（`src/utils/category-tree.ts#getCategoryFromId`）：取 id 最后一个 `/` 之前的部分；放在 posts 根目录的文章属于「未分类」（`/categories/uncategorized/`）
- 支持多级文件夹嵌套（如 `技术分享/前端/xxx.md`），父分类页会包含所有子孙分类的文章
- frontmatter 中历史遗留的 `category` 字段已废弃，不要再写
- 文件名即文章 URL 的最后一段，中英文与空格均可（如 `Meting-API-使用指南.md`），**不带日期前缀**（PagesCMS 后台新建除外）

## Frontmatter 字段

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `title` | string | 是 | — | 文章标题 |
| `published` | date | 是 | — | 发布时间，YAML 写 `2026-07-26` 或 `2026-07-26 12:00:00` 均可 |
| `updated` | date | 否 | — | 最后更新时间；填写后文章页展示「最后更新于」 |
| `draft` | boolean | 否 | `false` | 草稿。**生产构建（PROD）会隐藏草稿**，本地 `pnpm dev` 仍可见 |
| `description` | string | 否 | `""` | 摘要；用于列表卡片、文章简介面板、SEO、RSS、分享海报，留空时自动截取正文 |
| `image` | string | 否 | `""` | 封面图。支持 `https://` 远程 URL、`/` 开头的 public 路径、相对当前 md 的相对路径、特殊值 `"api"`（随机图 API）；留空时列表回退随机封面 |
| `tags` | string\[] | 否 | `[]` | 标签，如 `[指南, 音乐]`（YAML 块式或行内数组均可） |
| `lang` | string | 否 | `""` | 文章语言声明（如 `en`、`zh_TW`、`ja`、`ru`），仅用于设置页面 `<html lang>` 与 SEO；**不是双语机制**，一篇文章一个文件，不需要为其他语言建副本 |
| `pinned` | boolean | 否 | `false` | 置顶；置顶文章在列表/分类中排在最前并显示置顶徽章 |
| `order` | number | 否 | — | 同一天发布的文章，在所属分类目录内按 `order` 降序排（值越大越靠前），未写排在最后 |
| `author` | string | 否 | `""` | 作者名（转载/多人写作时使用） |
| `sourceLink` | string | 否 | `""` | 转载来源链接 |
| `licenseName` | string | 否 | `""` | 自定义协议名称（转载文章声明版权时使用） |
| `licenseUrl` | string | 否 | `""` | 自定义协议链接 |
| `comment` | boolean | 否 | `true` | 文章页是否显示 Waline 评论区，设为 `false` 可关闭单篇评论 |
| `prevTitle` / `prevSlug` / `nextTitle` / `nextSlug` | string | — | `""` | **内部字段，禁止手填**：构建时按排序自动回填上一篇/下一篇 |

> 封面建议尺寸 **1600×900（16:9）webp**，可走 AI 封面脚本统一生成（见下文 CLI）。

## 排序规则

`src/utils/content-utils.ts#comparePostsByOrderAndDate`：

1. `pinned: true` 最前
2. `published` 降序（新发布在前）
3. 同一天内先按分类目录名（`zh-CN`）分组
4. 同组内按 `order` 降序，未写 `order` 视为最小（排该目录当天最后）

排序完成后自动回填每篇文章的上一篇/下一篇链接。

## 快速创建（CLI）

- `pnpm cli new <文件名>`：在 `src/content/posts/` 下创建文章（可带子目录，如 `pnpm cli new 技术分享/我的新文章`，会自动建目录、补 `.md`），模板含 `title`、`published`（当天）、`description`、`image`、`tags`、`draft`、`lang`
- `pnpm cli cover`：调用 AI 批量/单篇生成 16:9 封面
- `pnpm cli desc`：AI 生成摘要
- 不带参数运行 `pnpm cli` 进入交互菜单
- 也可以在 PagesCMS 后台（cms.tsh520.cn）新建，后台文件名模板为 `YYYY-MM-DD-<标题>.md`

## 示例

常规文章：

```yaml
---
title: Meting-API-使用指南
published: 2026-07-26
image: https://img.tsh520.cn/file/blog/post-covers/tech-05-meting-api-guide.webp
order: 1
tags:
  - 宝塔面板
  - 音乐
  - 指南
description: 介绍如何使用Meting-API
---

> 正文从这里开始，支持完整 Markdown / MDX。
```

转载文章（草稿 + 关闭评论）：

```yaml
---
title: 某篇转载
published: 2026-09-01
draft: false
author: 原作者
sourceLink: https://example.com/original
licenseName: 版权归原作者所有
licenseUrl: https://example.com/license
comment: false
tags:
  - 转载
---
```
