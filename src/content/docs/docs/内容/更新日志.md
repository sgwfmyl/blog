## 概述

更新日志集合用于 `/changelog` 页面的功能迭代时间轴（站点版本历史）。

- **物理目录**：`src/content/changelog/**/*.{md,mdx}`，一个文件 = 一条版本记录
- **集合定义**：`src/content.config.ts` 的 `changelogCollection`
- **展示页面**：`src/pages/changelog.astro`（受 `siteConfig.pages.changelog` 开关控制），时间轴组件 `src/components/about/ChangelogGraph.astro`
- 条目按 `date` 倒序（`src/utils/changelog.ts`）

## Frontmatter 字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `version` | string | 是 | 语义化版本号，带 `v` 前缀，如 `v1.60.1` |
| `date` | date | 是 | 发布日期 `YYYY-MM-DD` |
| `time` | string | 否 | 发布时间，如 `"00:40"` |
| `type` | enum | 是 | 变更类型：`feature`（新功能）/ `improvement`（改进）/ `fix`（修复）/ `removal`（移除） |
| `description` | string | 是 | 一句话摘要，显示在时间轴卡片上 |

正文（frontmatter 之后）写详细说明：惯例用 `## 标题` 开头，再用无序列表展开细节；点击卡片可在弹窗中查看正文。

## 文件命名规则

`YYYY-MM-DD-<kebab-case简述>.md`，如：

- `2026-10-11-guestbook-moment-quote-render.md`
- `2026-05-17-changelog-page.md`

同一天可有多条（不同后缀即可）。

## 版本号递增规则

遵循语义化版本（major.minor.patch），与变更类型挂钩：

- `feature`（新功能）/ `removal`（移除功能）：**minor +1**，如 `v1.59.3` → `v1.60.0`
- `fix`（修复）/ `improvement`（改进）：**patch +1**，如 `v1.60.0` → `v1.60.1`

每完成一个模块/功能立即写一条，不要攒批（工程规范 CLAUDE.md §21）。

## 示例

```yaml
---
version: v1.60.1
date: 2026-10-11
time: "00:40"
type: fix
description: 修复留言板拉取评论时不解析 MOMENT 引用前缀，导致动态引用以原始协议文本显示的问题
---

## 留言板动态引用渲染修复

留言板从服务器拉取评论时，消息构造只解析了回复标记，没有解析说说的引用前缀……

- **修复**：`normalizeGuestbookComment` 增加 MOMENT 前缀解析
- **HTML 兼容**：新增 `parseMomentQuoteFromHtml`，兼容游客请求下的转义 HTML
- **类型**：补充可选 `momentQuote` 字段
```
