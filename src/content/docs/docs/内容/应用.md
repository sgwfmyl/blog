## 概述

应用集合用于 `/apps` 页面的应用/工具推荐卡片墙（带标签筛选与分页）。

- **物理目录**：`src/content/apps/**/*.md`，一个文件 = 一个应用
- **集合定义**：`src/content.config.ts` 的 `appsCollection`
- **展示页面**：`src/pages/apps.astro`（`/apps`）

## Frontmatter 字段

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `title` | string | 是 | — | 应用名称 |
| `imgurl` | string | 是 | — | 图标 URL，常用官网 favicon（如 `https://claude.ai/favicon.ico`） |
| `desc` | string | 是 | — | 应用简介 |
| `siteurl` | string | 是 | — | 应用官网/访问链接 |
| `tags` | string\[] | 否 | `[]` | 标签；页面聚合成顶部筛选按钮（如 `AI`、`开发工具`） |
| `weight` | number | 否 | `0` | 排序权重，越大越靠前 |
| `enabled` | boolean | 否 | `true` | 是否展示，`false` 软下线 |

## 排序与展示

- 按 `weight` 降序
- 全部 `tags` 聚合为筛选标签，点击过滤卡片；每页 9 张分页
- 卡片点击新窗口打开 `siteurl`

## 文件命名规则

惯例数字前缀 + 名称，如 `01-claude-code.md`（前缀仅方便文件管理，排序以 `weight` 为准）。

## 示例

```yaml
---
title: Claude Code
imgurl: https://claude.ai/favicon.ico
desc: "Anthropic 官方的 AI 编程助手，支持代码生成、调试、重构等工作流。"
siteurl: https://claude.ai/code
tags:
  - AI
  - 开发工具
weight: 10
enabled: true
---
```
