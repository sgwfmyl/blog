## 概述

spec 集合存放几个**特殊页面的正文内容**（Markdown/MDX）。这些文件不生成独立路由，而是被对应页面用 `getEntry("spec", ...)` 读取后嵌入渲染。

- **物理目录**：`src/content/spec/**/*.{md,mdx}`
- **集合定义**：`src/content.config.ts` 的 `specCollection`（**空 schema**：不校验任何 frontmatter 字段，正文自由）
- 当前条目：

| 文件 | 嵌入位置 |
| --- | --- |
| `about.mdx` | `/about` 关于页（`src/pages/about.astro`） |
| `friends.md` | `/friends` 友链页底部的正文区 |
| `guestbook.md` | `/guestbook/` 留言板页（`src/pages/life/guestbook.astro`）顶部说明 |
| `projects.md` | 预留文件，当前没有页面引用 |

## 使用规则

1. **修改正文**：直接编辑对应 md/mdx 文件即可，页面构建时读取渲染
2. **MDX 能力**：以 `.mdx` 结尾的文件可以 `import` 组件并在正文里使用——关于页正是这样嵌入 `AboutProfileCard`、`AboutTechStack`、`AboutTimeline` 等交互式组件的
3. **新增条目**：仅新建文件**不会**出现在任何页面，必须同时在某个 `.astro` 页面里用 `getEntry("spec", "<文件名>")` 取出并 `render()` 后才会展示
4. 因为 schema 为空，frontmatter 可以不写；写了 `title`/`description` 等字段也会被忽略，不参与渲染

## 示例（about.mdx 片段）

```mdx
import AboutTechStack from "@/components/about/AboutTechStack.astro";

## 关于我 / About Me

我在这里记录我的日常，也记录一些学习分享，用来留存记忆。

### Q1：这个站点用到了哪些技术栈？

具体用了哪些技术，点开下面看看吧：

<AboutTechStack />
```
