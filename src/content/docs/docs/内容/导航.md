## 概述

导航集合用于 `/projects` 导航页（站名常称「网址导航」）：按分类分区展示网站卡片，支持搜索与标签筛选。

- **物理目录**：`src/content/daohang/**/*.md`，一个文件 = 一张导航卡片
- **集合定义**：`src/content.config.ts` 的 `daohangCollection`
- **展示页面**：`src/pages/projects.astro`（`/projects`）

## 文件夹即分类

- 卡片所在的**父文件夹名就是分类名**，如 `daohang/AI/DeepSeek.md` 归到「AI」分类
- 现有分类：`我的网站`、`常用网站`、`AI`、`API`、`工具网站`、`开发者工具`、`开发者服务平台`、`学习网站`、`文档`、`设计资源`、`实用项目`
- 分类在页面上的展示顺序在 `projects.astro` 的 `CATEGORY_META` 中登记（按 order 排序）；**新建分类后如需固定位置，要在该配置里登记**，未登记分类排到最后
- 分类内卡片按 `name` 中文拼音（`zh-CN`）排序

## Frontmatter 字段

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `name` | string | 是 | — | 网站名称 |
| `url` | string | 是 | — | 网站链接 |
| `icon` | string | 否 | `""` | 图标。**以 `http://`、`https://` 或 `/` 开头 → 当作图片地址**（如 `/assets/ziyuan/logo01.png`、`https://xxx/favicon.ico`）；否则当作 **Iconify 图标名**（如 `fa7-brands:font-awesome`）；留空显示默认图标 |
| `description` | string | 否 | `""` | 卡片描述，参与搜索匹配 |
| `tags` | string\[] | 否 | `[]` | 分类内子标签：同一分类下出现过的标签聚成一排子标签按钮，点击在该分类内按标签「与」筛选 |

搜索同时匹配卡片名称、描述与链接域名。

## 示例

本地图片图标：

```yaml
---
name: 个人博客
url: https://blog.5484826.xyz/
icon: /assets/ziyuan/logo01.png
description: 个人技术与生活分享博客
tags:
  - 站点
---
```

Iconify 图标 + 标签（文件如 `daohang/AI/某站.md`）：

```yaml
---
name: 某 AI 网站
url: https://example.com
icon: fa7-brands:font-awesome
description: 在线 AI 工具
tags:
  - 免费
  - 在线工具
---
```
