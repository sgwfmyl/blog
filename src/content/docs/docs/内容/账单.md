## 概述

账单集合用于 `/bills` 记账页面：按月/年展示收支流水、每日趋势、分类排行。

- **物理目录**：`src/content/bills/**/*.{md,mdx}`，一个文件 = 一笔账单
- **集合定义**：`src/content.config.ts` 的 `billsCollection`
- **展示页面**：`src/pages/bills.astro` + `src/components/bills/`（8 个统计/流水组件）
- **没有页面表单和写接口**：账单只能通过 **PagesCMS 后台**（cms.tsh520.cn）或直接新建 md 文件录入

## Frontmatter 字段

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `amount` | number | 是 | — | 金额。**支出写负数（如 `-20`），收入写正数（如 `2500`）**；统计时取绝对值 |
| `type` | enum | 否 | `expense` | 类型：`expense`（支出）/ `income`（收入） |
| `category` | string | 否 | `"其他"` | 分类，自由字符串，如 `餐饮`、`交通`、`人情往来`、`职业收入` |
| `account` | string | 否 | `"其他"` | 账户，自由字符串，如 `微信`、`支付宝`、`现金` |
| `date` | date（自动 coerce） | 是 | — | 账单日期 `YYYY-MM-DD`，流水按它降序 |
| `time` | string | 否 | `""` | 发生时间，严格 `HH:mm` 格式（如 `20:06`）；同一天内按它**降序**并显示在流水行首 |
| `title` | string | 否 | `""` | 标题（PagesCMS 新建时用文件名生成） |
| `description` | string | 否 | `""` | 备注 |
| `tags` | string\[] | 否 | `[]` | 标签 |

> `category` / `account` 没有枚举配置文件，均为自由文本，靠录入时保持文案一致来聚合统计。收入侧的「工资」会在统计层并入「职业收入」。

## 文件命名规则

- 惯例 `YYYY-MM-DD-<事由>.md`，如 `2026-08-29-买彩票.md`
- PagesCMS 后台新建自动套用该模板，重名自动追加 `-1`
- 正文可写补充说明（非必需）

## 统计规则

- 页面构建时生成：本月/本年收支汇总、每日趋势、按月流水、分类排行（`src/utils/bill-adapter.ts`），时间基准为**构建时的当前月份**
- 因此想看到最新月份的统计，发布/重新构建后才会更新

## 示例

支出（金额为负）：

```yaml
---
title: 买彩票
amount: -20
type: expense
category: 其他
account: 微信
date: 2026-08-29
time: "20:06"
description: 买彩票
tags:
  - 其他
---
```

收入（金额为正）：

```yaml
---
title: 老爸转账
amount: 2500
type: income
category: 人情往来
account: 微信
date: 2026-08-23
---
```
