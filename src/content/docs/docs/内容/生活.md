## 概述

生活集合是一个「大杂烩」schema，历史上承载过多种生活记录。**目前实际在用的只有「足迹」**（`places/` 子目录）；打卡计划相关字段已定义但功能未上线，部分旧字段已废弃。

- **物理目录**：`src/content/life/**/*.{md,mdx}`，glob 递归扫描
- **集合定义**：`src/content.config.ts` 的 `lifeCollection`
- **展示页面**：足迹地图 `src/pages/life/places.astro`（路由 `/footprint/`，高德地图）
- 消费方一律按 **id 前缀过滤**：只有 `places/` 前缀的条目算足迹；`notebooks/` 子目录虽然也在 `life/` 物理目录下，但笔记本属于**独立的 notebooks 集合**（见《笔记本》文档），各处统计都会排除，不会重复

## 足迹（places，在用）

### 文件组织

- 全部放在 `src/content/life/places/` 下
- 文件名惯例 `YYYY-MM-DD.md` 或 `YYYY-MM-DD-地点.md`，如 `2026-08-21-商丘市虞城县倒楼村.md`
- **一次到访一个文件**：同一地点不同日期去了多次，就建多个文件（页面用 `visitCount`/日期汇总到访次数）

### Frontmatter 字段

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `date` | date（自动 coerce） | 是（惯例） | — | 到访日期，页面按它降序排列 |
| `province` | string | 否 | `""` | 省份，如 `陕西省` |
| `city` | string | 否 | `""` | 城市/具体地点，如 `华阴市华山` |
| `experience` | string | 否 | `""` | 游玩体验/正文感受，显示在地图弹窗中 |
| `visitCount` | number | 否 | `1` | 到访次数 |
| `lat` | number | 否 | — | 纬度（GCJ-02 高德坐标），地图标点用 |
| `lng` | number | 否 | — | 经度 |
| `photos` | string\[] | 否 | `[]` | 照片 URL 列表，统一使用图床地址 |
| `url` / `urlLabel` | string | 否 | `""` | 关联链接与链接文案（如关联到对应说说/相册） |
| `tags` | string\[] | 否 | `[]` | 标签，常用 `旅游` + 年份 |

地图使用高德地图 JS SDK，key 取环境变量 `PUBLIC_AMAP_KEY_PLACES`；未配置时地图无法加载。

### 示例

```yaml
---
date: 2025-05-01
province: 陕西省
city: 华阴市华山
visitCount: 1
lat: 34.477861
lng: 110.084789
photos:
  - https://img.tsh520.cn/file/blog/moments/1000023768.jpg
tags:
  - 旅游
  - "2025"
---
```

## 打卡计划（plan，未上线）

schema 中保留了以下字段，但**当前没有任何页面或后台消费**（无数据文件、`.pages.yml` 无配置），仅为预留：

| 字段 | 类型 | 默认值 | 预留含义 |
| --- | --- | --- | --- |
| `planName` | string | `""` | 计划名称 |
| `targetDesc` | string | `""` | 目标描述 |
| `dailyTarget` | number | `1` | 每日目标 |
| `monthlyTarget` | number | `20` | 每月目标 |
| `checkins` | date\[] | `[]` | 打卡日期列表 |

功能上线前不建议使用这些字段创建内容。

## 已废弃字段（仅留兼容）

以下字段没有任何页面消费，**不要再写**，schema 保留只是为了不破坏历史数据：

- `waterCups`（喝水杯数）、`meals`（三餐记录）、`streak`（连续天数）、`progress`（进度百分比）
- 通用遗留字段 `label` / `value` / `status` / `entries` / `createdAt` / `completedAt` / `updatedAt`：旧版生活页遗留，足迹与计划均不需要
