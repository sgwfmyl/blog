本文档讲解项目 `scripts/` 目录下的全部自定义脚本**功能**，帮助你了解它们各自能做什么、何时使用。所有脚本均不参与博客页面渲染，仅作为开发/内容维护阶段的辅助工具。

- **脚本目录**：`scripts/`
- **统一入口**：`cli.js`（推荐通过 `pnpm cli` 调用）

***

## 一、统一入口（`cli.js`）

所有高频命令都通过 `scripts/cli.js` 统一调度，你只需记住一条命令：

```bash
pnpm cli
```

- 直接运行 `pnpm cli` 会进入**交互菜单**，按编号或命令名选择要执行的操作，并逐步询问参数（回车可跳过可选项）。
- 也可以**子命令直达**，例如 `pnpm cli media "星际穿越"`，额外参数会原样转发给对应脚本。
- 运行 `pnpm cli <命令> --help` 可查看单个命令的用法。
- 交互菜单还有「中文输入猜测」：当你输入中文但无法匹配命令时，会询问是否是想下载影视。

### 可用命令一览

| 命令       | 功能                          | 对应脚本            |
| -------- | --------------------------- | --------------- |
| `new`    | 创建一篇新文章                     | `新建文章/index.js` |
| `moment` | 创建一条说说（moments 动态）          | `新建说说/index.js` |
| `media`  | 搜索下载影视封面并生成博客 md（TMDB）      | `下载影视/index.py` |
| `desc`   | 用 AI 批量生成文章摘要               | `生成摘要/index.ts` |
| `nav`    | 添加网站导航条目（自动抓取 ICO 图标）       | `添加导航/index.js` |
| `dev`    | 启动本地开发服务器（等价 `pnpm dev`）    | —               |
| `build`  | 构建生产站点（含图标生成 + Pagefind 索引） | —               |

## 二、内容生成类脚本

以下脚本用于生成新增的内容文件（文章、说说、导航、影视/音乐条目）。

### 新建文章（`新建文章/index.js`）

对标博客系统的标准写作模板创建 `.md` 文件并自动填充 frontmatter（标题、日期、分类等），文件名可省略 `.md` 后缀。适合在浏览器后台之外用命令行快速开篇一篇新文章。

### 新建说说（`新建说说/index.js`）

创建一条 moments 说说动态。文件名按当前系统时间生成（年月日 + 时分），即使同一天发多条也不会重名；Frontmatter 会展示全部默认字段，正文可直接作为命令行参数传入。

### 添加导航（`添加导航/index.js`）

为「导航」页面新增一条链接。只需提供网站地址，脚本会自动抓取该站点的 ICO 图标，并引导填写名称、描述、分类、标签等信息，最终生成 Markdown 文件到导航内容目录。内置了常用分类（如「工具网站」「设计资源」）便于选择。

### AI 摘要生成（`生成摘要/index.ts`）

为**缺失** **`description`** **的文章**批量自动生成摘要，已有摘要的文章会被跳过、不会覆盖。运行前需在项目根目录 `.env` 中配置 `DASHSCOPE_API_KEY`（密钥切勿写进被 git 跟踪的文件）。

## 三、媒体下载类脚本

用于从外部平台检索影视信息，并自动落成博客所需的内容文件。

### 影视封面（`下载影视/index.py`）

从 TMDB 搜索影视作品（电影/电视剧/动漫/纪录片），下载封面并生成对应的 bangumi md 文件。支持快速模式（自动选择第一个结果、跳过交互确认）、预设观看状态与评分，以及 TMDB 搜不到时自动降级为手动录入模式。

## 四、图像处理类脚本

以下脚本负责站内图片素材的优化与整理，多数是对本地 `public/` 下的图片做格式化处理。

### 图标预处理（`生成图标/index.js`）

在 **构建时自动执行**：扫描 Svelte 组件中使用的图标，将其转换为内联 SVG 数据，避免运行时逐字加载图标库，从而优化页面性能。无需手动运行。

### 图片转 WebP（`转WebP/convert-to-webp.mjs`）

把 `jpg/png/jpeg/avif/gif` 等图片批量转为 WebP 格式，并压缩到适合网站的大小（限制最大宽度与质量）。已符合规范的小体积 WebP 会跳过、保留原名；其余统一重命名为数字序列，方便引用。

### 批量压缩图片（`compress-images.mjs`）

对指定或全部图片目录做尺寸/质量压缩以减小体积，可自定义质量与最小文件阈值，支持「仅预览」试跑。

### 其他处理脚本

- **`rename-images.mjs`**：把封面图集中的图片重命名为数字形式，并同步更新对应的封面配置文件。
- **`import-wallpapers.mjs`**：从本机「好玩么壁纸」应用下载目录批量导入壁纸到站点资源目录，并重命名 + 更新配置。

## 五、友链与运维辅助类脚本

服务于友链页的可用性检测、截图展示，以及日常开发/排错。

### 友链状态检测（`友链状态检测/index.mjs`）

逐个请求友链站点的 URL，记录响应时间并评定快慢分档，最终输出状态数据文件供友链页展示。结果默认提交回仓库，由 CI 定时执行后反映在页面上。

### 友链截图（`友链截图/index.mjs`）

用无头浏览器逐个访问友链站点，截取首页并压缩为站点缩略图供友链卡片展示。可只截取单个友链并强制覆盖已有截图，或忽略已存在截图全部重拍。

### 视觉识别（`vision.mjs`）

调用第三方视觉模型识别图片内容，可用文字提问（例如「这张截图里有什么错误信息？」）。支持传入本地图片路径或网络图片 URL，也支持自动寻找最新一张图片。用于快速理解/排查图片内容。

### 压缩 Svelte 警告检查（`check-svelte-warnings.mjs`）

编译指定的若干 Svelte 组件，输出编译器警告，用于修复组件警示时的循环验证。
